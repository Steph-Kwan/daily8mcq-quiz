# 题库格式

一份题库就是一个 Excel 表格（`.xlsx`，也可以用 `.csv`），每行一道题。有配图的话，把图片和表格放在同一个文件夹里，打包成 `.zip` 导入；也可以在导入时把表格和图片一起选中。

最快的上手方法：在 App 的「题库管理」页面下载**空白模板**或**示例题库**，照着修改。也可以直接用仓库里的 [`demo/template.xlsx`](../demo/template.xlsx) 和 [`demo/demo.xlsx`](../demo/demo.xlsx)。

## 「题目」工作表

第一行是表头，列的顺序随意。中文和英文列名都能识别。

| 列名 | 英文列名 | 必填 | 说明 |
|---|---|---|---|
| 题目 | question | 题目和图片至少填一项 | 题目文字，可以换行。整道题是截图时可以留空。 |
| A、B、C、D、E、F | A … F、option A | 二选一 | 选项文字，最多 6 个，用几个填几个。也可以填图片文件名，或者把图片直接粘贴进单元格。 |
| 答案 | answer | ✓ | 单选填一个字母（`B`）；多选填多个（`ACD`，写成 `A,C,D` 或 `A、C、D` 也行）；判断题填 `对` / `错`（`√ × T F 正确 错误` 也能识别）。大小写不限。 |
| 题型 | type | | `单选` / `多选` / `判断`。可以不填：答案有多个字母会自动当成多选，答案是对 / 错且没有选项时自动当成判断。 |
| 分类 | category、topic | | 知识点、章节或题型分类。首页按它分类练习，复习计划按它统计掌握情况。不填就是「未分类」。 |
| 图片 | image | | 题目配图的文件名，多张用分号 `;` 隔开。 |
| 解析 | explanation | | 订正时显示在答案下面；使用 AI 讲解时也会提供给 AI 参考。 |
| 来源 | source | | 例如 `2024 Q3`、`第二章练习`，首页可以按来源筛选。 |
| 编号 | id | | 每道题的固定编号。**以后要更新题库（改错字、补题），建议填写**：编号不变的题，学习记录会保留。不填时按题目内容自动生成编号，所以改动题目文字后会被当成新题。 |
| 选项数 | option_count | | 整道题是截图、选项也在图里、表格里没有选项文字时，用它说明有几个选项（默认 4）。 |
| 难度 | difficulty | | 暂时没有用到，导入时会保留，方便以后使用。 |
| 标签 | tags | | 用逗号或空格隔开，可以在「浏览题目」里搜索。 |

### 三种放图片的方法

1. **整题截图**：「题目」留空，「图片」填截图文件名，「选项数」写选项个数。适合已经有试卷截图的情况。
2. **文字加配图**：「题目」写文字，「图片」填图表的文件名。
3. **直接粘贴**：在 Excel 里把图片粘贴到这一行的单元格上，导入时会自动识别。图片放在 A–F 选项列里，就成为该选项的图片；放在其他列，就成为题目配图。

支持的图片格式：png、jpg、gif、webp、svg。AI 讲解会读取题目和选项里的图片（svg 会先转成普通图片）。

## 「设置」工作表（可选）

第一列写项目，第二列写值：

| 项目 | 说明 |
|---|---|
| 名称 | 题库名称，不填就用文件名。 |
| 简介 | 显示在首页标题下面。 |
| 每轮题数 | 默认每轮几题（默认 8，练习时也可以改）。 |
| 编号 | 题库的固定编号。导入同一编号（或同一名称）的题库，会**更新**原题库而不是新增一份，学习记录会保留。 |

其他工作表（比如模板里的「说明」）会被忽略。如果没有名为「题目」的工作表，App 会使用第一个表头能识别的工作表。

## CSV

`.csv` 文件的表头规则和上面相同，只是不能放「设置」工作表，也不能粘贴图片（可以用「图片」列加图片文件）。文件请保存为 UTF-8 编码；从 Excel 导出时选择「CSV UTF-8」。

## 导入时会检查什么

导入前会先显示预览：一共多少题、分哪些类、有多少张图片，以及有问题的行。

- **错误**（这一行不导入）：题型无法识别；答案格式不对（比如单选题写了两个字母，或者答案是 E 但只有 4 个选项）；没有题目内容；编号重复。
- **提醒**（这一行照常导入）：找不到图片文件；没有填写答案（这题只能浏览，不会出现在练习里）。

每条问题都会标出它在表格里的行号，改好后重新导入即可。
